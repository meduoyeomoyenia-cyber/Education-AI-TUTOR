# Phase 0 — Locked MVP Scope

## In (MVP)
- Onboarding: class SS1-SS3, exams WAEC/NECO/JAMB/school, subjects, language EN/Pidgin/Yoruba/Hausa/Igbo, style, confidence, career → guidance blurb
- Learn / Practice / Exam / Ask AI / Revision
- Text AI tutor, voice input OPTIONAL (never required)
- Progress: syllabus %, strengths/weaknesses, streak, recent mistakes
- Data Saver ON by default on slow networks

## Out (v2)
Live Q&A scale, study groups scale, parent portal, full teacher dashboard, AI video scale.

## Mastery rule
Topic = Mastered if >=80% on mixed set of >=10 questions AND no repeat of same mistake-tag within 7 days.
Progress counts only assessed mastery, never lesson opens.

## Data budgets (enforced)
- Text lesson <50KB, practice session <500KB, 30-min session <2MB on Data Saver
- Images lazy + low-res placeholder, audio 32-48kbps, video never required, 720p max compressed via R2+CDN

## Content legality
Original + teacher-created + licensed WAEC/NECO/JAMB-style only. Every question has source/license field. No scraped past papers.

## Success gates
D7 return >30%, assessment score delta positive, repeat-mistake rate falling, KB/session within budget, tutor engagement, zero safety incidents.
