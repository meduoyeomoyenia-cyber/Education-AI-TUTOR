# Phase 9 — Pilot, Measure, Iterate (100-300 students, 2-3 schools)

## Pilot setup
- Cohort: SS1-SS3, WAEC/NECO/JAMB mix. Onboard via `/onboarding`, Data Saver ON.
- Duration: 2 weeks. Teachers review flagged answers daily via `content/review_queue.md`.

## Metrics (run `python scripts/pilot_check.py`)
- return_rate, lessons/topics mastered, assessment delta, repeat-mistake rate, KB/session, tutor engagement, satisfaction (survey), safety incidents
- Exit gates: D7 >30%, mock improvement >0, session <2MB/30min, zero unresolved safety, repeat-mistake falling

## Iterate
Fix top 3 drop-offs, content gaps, multilingual clarity (PCM/YO/HA/IG), data overruns. Load-test mocks.
